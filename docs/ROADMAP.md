# IpoVideo 重做路线图

## 学习方式

每个阶段固定四件事：

1. **产品问题**：这一阶段解决用户的哪个痛点。
2. **技术知识**：讲清楚概念和为什么，再动手写。
3. **代码产出**：可运行、可测试、可演示。
4. **验收与作业**：你独立完成一个小任务，并回答面试问题。

建议你在学习代码的同时补 Java 基础（类、对象、方法、集合、异常），
不需要等全部学完，跟着阶段走、缺什么补什么最快。

## 阶段总览

| 阶段 | 产品问题 | 技术点 | 产出 |
| :--- | :--- | :--- | :--- |
| 0 环境与认知 | 理解产品和技术全貌 | HTTP、后端定位、开发环境 | 本路线图 |
| 1 MVP 主链路 | 用户能注册登录 | Spring Boot、REST、H2、MyBatis-Plus、会话 | 注册/登录/我的信息 |
| 2 真实数据层 | 数据不能丢、结构要稳定 | MySQL、Flyway、事务、索引 | 数据库迁移与事务化改造 |
| 3 异步任务 | 分析很慢不能卡住用户 | 任务表、线程池、SSE 进度、状态机 | 上传即返回 + 进度推送 |
| 4 缓存与限流 | 接口要快、资源要可控 | Redis、缓存、限流、分布式锁 | 会话入 Redis、登录限流 |
| 5 消息队列 | 高并发下削峰解耦 | RocketMQ、生产者/消费者、重试 | 分析任务投递 MQ |
| 6 对象存储 | 大文件上传与保存 | MinIO、分片上传、断点续传、MD5 | 分片上传 API |
| 7 AI Agent | 结论要可信、可追溯 | LLM 接入、结构化输出、Planner-Executor-Critic | Agent 分析链路 |
| 8 长视频处理 | 语音画面都要理解 | FFmpeg、ASR、OCR、VideoContext | 多模态上下文构建 |
| 9 向量检索 | 长视频上下文太大 | Embedding、Qdrant、混合检索、降级 | 检索召回模块 |
| 10 工程化 | 能测试、能部署 | 单测/集成测试、Docker、CI、日志监控 | 一键启动与 CI |
| 11 简历与面试 | 把成果讲出来 | 简历写法、项目问答、模拟面试 | 简历终稿 |

## 简历话术（最终形态，随阶段逐步完善）

一句话版本：

> IpoVideo：面向长视频内容理解的 AI Agent 平台。基于 Java 21 + Spring Boot 3 + MySQL + Redis +
> RocketMQ + MinIO + Qdrant + LangChain4j 构建，支持分片上传、异步削峰、带证据约束的
> Planner-Executor-Critic Agent 工作流，结论可回溯到原视频时间戳。

注意：简历只能写你真正理解并做过的内容。每个阶段完成后，
我们会把对应的一句话加进"简历素材.md"，由你自己确认。
